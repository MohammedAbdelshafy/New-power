# Contributing (agents & humans)

Read `CLAUDE.md` and `MBM/CONSTITUTION.md` first. All work flows through missions (`bash scripts/mbm.sh status`). Claim before executing; push claims immediately. `bash scripts/smoke-test.sh` must pass before release tags (`Release/RELEASE_CHECKLIST.md`). Small atomic commits; `git mv` for moves; never rewrite history; docs update in the same commit as behavior.
